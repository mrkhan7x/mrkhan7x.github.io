What It Does

A modular 5-agent pipeline that replaces an entire content team by orchestrating the video production lifecycle from trend discovery to final metadata.

1

Agent 1: Trend & Hook Strategist

Scrapes top community discussions (via Reddit API or webhook topic triggers), identifies high-engagement questions, and formulates high-retention hook angles.

2

Agent 2: Script & Scene Architect

Converts the hook into a full retention-focused script, dividing narration into 8-second visual scene prompts and visual direction cues.

3

Agent 3: ElevenLabs Voiceover Engine

Cleans script timing, sends formatted narration to ElevenLabs, and generates studio-quality voiceover audio automatically.

4

Agent 4: Video Assembly Specifier

Calculates scene durations, audio timestamps, and programmatic cut points ready for automated rendering (Shotstack / Remotion / Creatomate).

5

Agent 5: Packaging & SEO Specialist

Analyzes the final script to produce 3 high-CTR title variations, search-optimized descriptions, tags, and chapter markers.

✓

Production Logging & Delivery

Logs all assets into a Google Sheets pipeline tracker and returns the complete production package via webhook response.
